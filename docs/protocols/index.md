# Protocols

WebAgents defines UAMP, a protocol specification for agent communication, and documents AOAuth, Robutler's named profile of the Web Bot Auth drafts for agent authentication.

- [UAMP](./uamp.md) — Universal Agentic Message Protocol — event-based protocol unifying agent communication across transports, providers, and frameworks
- [AOAuth](./aoauth.md) — Robutler's named profile of Web Bot Auth for agent authentication, built on RFC 9421 HTTP Message Signatures

For the practical route rather than the wire format, see [Self-Registration](../guides/self-registration.md).
