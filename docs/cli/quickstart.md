# CLI Quickstart

The [Quickstart](../quickstart.md) is the command-line quick start: install the
`webagents` command, chat in an empty folder, write and run an agent file, and
serve it over HTTP. Its last step,
[Put it on Robutler](../quickstart.md#5-put-it-on-robutler), is
`webagents login` then `webagents publish`.

- [Commands](./commands.md): every command and flag.
- [Chat](./repl.md): the chat's commands, keys and conversations.
- [Publish](./deploy.md): linking, keys and platforms.
- [Configuration](./configuration.md): the agent file's keys, and shared
  context in `WEBAGENTS.md`.
